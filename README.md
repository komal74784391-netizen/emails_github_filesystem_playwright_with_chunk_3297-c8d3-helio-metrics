# Helio Metrics

Catalog entry: `catalog/helio-metrics.md`

Collects nightly usage telemetry from the Helio Labs deployment fleet.

## Availability

Public source is available under Apache-2.0. Current release line: 2.4.0 (published 2026-06-18 on the `public/2.4.0` branch).

## Layout

- `src/` — implementation modules
- `tests/` — unit tests
- `results/` — validation output produced by the release run
